# 字幕工坊：结构完整性与复核

2026-09-18：本轮源码版本 Studio 0.1.13 / llmtranslate 0.1.8；保留现有 ASR 0.2.0 / writer 0.1.4。继续原字幕优化任务，修复实际报告暴露的重译上下文与复核状态问题。

## 本轮行为

- 保留原始 SRT ID 和时间轴。非空损坏 SRT、重复源 ID、空文本、非法时间轴直接失败，不能当作静音跳过。
- 模型必须正常 `finish_reason=stop`，严格输出且仅输出每个目标 ID 的一条非空译文。缺失、重复、额外编号、说明文字、截断和异常完成均拒绝。
- 每个目标块及二分重试提供前后各三条原文，不会把前块译文当作原文上下文。完整含义优先，不限制固定汉字数，也不在翻译步骤强制换行。
- writer 写入目标文件前核对原文/译文的 ID、条目数与每条起止时间。合法零条目仍支持空字幕输出。
- 零时长条目完整保留，不删除、不合并、不自动补时长。ASR 结果与缓存元数据、任务列表、HTML/JSON 对照报告列出 `zero_duration` 警告及原编号/时间轴；语言未知导致翻译暂停时，任务列表仍保留警告。
- ASR 拼接跨数据包的语言行，并将语言元数据与 raw.srt 一起缓存。非空字幕语言未知时，在调用翻译模型前失败。任务失败行可选择日语/英语后重试，无需重复 ASR；人工覆盖语言不等于重新听写。

## 对齐复核与诊断

每次进入翻译执行时，在 FMB 数据根的 `subtitle-reviews/<随机运行ID>/` 留下 `review.html` 和 `review.json`。任务表显示报告路径，选中复制后可在浏览器打开 HTML。报告含所有条目的原文、译文、ID 和时间轴，适合逐条及跨行人工核对。失败执行也会尽量保留报告；解析/语言/地址预检失败发生在报告初始化前，仅显示任务错误。

报告目录独立于 `subtitle-tasks/<taskId>`，writer 成功清理工作目录不会删除报告。报告包含字幕文本；删除 UI 任务也不会删除报告，请按路径自行管理保留期。

两个配置开关均默认关闭：

1. **额外模型质量复核**：翻译每块后，用当前配置模型核对原文/译文、前后原文、显式参考及说话人可用性，要求覆盖全部目标 ID。编号或复核响应契约不合法时失败；质量疑点则保留在报告并允许写出字幕。串位/遗漏沿用一次自动重译，重译后明确标为“已修订，待复核”，保存旧译文和原复核意见，不额外调用第二次复核。其他质量类别交由人工或原音核查，不自动猜改。正常路径每块增加一次请求，缓存恢复也需复核；网络重试或自动重译可能进一步增加费用，不会自动换模型。
2. **详细诊断**：增加 `diagnostics.jsonl`，保存请求正文、响应和失败原因；参考资料正文可能包含在请求中。配置快照和参考文件读取状态/内容 SHA-256 在 `review.json`。不写入请求头、API key 或本地 bearer token；已知凭据回显会脱敏，若出现在生成内容中则拒绝输出字幕。诊断写入失败会正常上报失败。

设置页标明当前生效的默认/覆盖模型和 API Base，仅代表后续执行配置。每次报告记录该次配置；API 返回的模型字段存在时另记 `responseModel`。没有历史快照的旧任务，不能据此推断历史实际模型。术语表及参考文件必须显式配置，没有自动加载 SUCCUBUSQ 人格或知识库。

复核提示与验证器共用 `quality-v1` 类别：`ok`、`shifted`、`omitted`、`pronoun_error`、`entity_mismatch`、`mistranslation`、`style_mismatch`、`asr_suspect`、`needs_audio`、`uncertain`。非 `ok` 必须有具体依据；一条有多个问题时优先报告需要原音确认的问题，其余写入 reason。`ok` 只表示“未检出所列问题”，不是准确性认证。JSON 的 source 回显也只能核对结构及来源绑定。

自动重译按被重译 ID 在完整原稿中的实际位置取前后三条原文；多个不连续 ID 之间的原稿以 `span_context` 提供，仅供理解，不列入翻译目标。断词、半句仍保持原始 ID 和时间轴。缓存保存修订后的文本，启用复核时恢复缓存不会绕过复核；缓存本身尚无完整配置/源稿指纹，变更输入或配置后的缓存复用需另行治理。

参考资料目前是全局后续任务配置，`glossaryPaths` 保存时替换整个列表，尚无作品/任务隔离。本轮没有加载或应用 SUCCUBUSQ 的作品配置补丁。通用知识已落实到复核契约；具体角色、称呼和作品词表必须等任务作用域明确后显式应用。
